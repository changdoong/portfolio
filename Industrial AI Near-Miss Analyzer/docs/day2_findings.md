## 3. COCO vehicle 기반 탐지의 한계

| 한계 | 관찰 근거 | 영향 |
|---|---|---|
| 지게차 클래스 없음 | 지게차가 truck / bus / car 로 프레임마다 다르게 검출 | 클래스로 지게차를 구분할 수 없음 |
| 정지 설비·카트 오검출 | 좌상단 파란 카트(car), 중앙 빨간 카트(car, 86개 조사에서 반복) | 움직이지 않는 물체와의 근접 후보 이벤트 발생 (6건 중 3건) |
| 수동 운반 장비 | 핸드 파렛트 트럭이 vehicle 로 검출 | 작업자와 본인이 끄는 장비 사이 근접이 후보로 기록 (2건) |
| 적재물만 보이는 각도 | 적재 박스가 truck 으로 검출 / 지게차 본체와 중복 박스 | 짧은 ID 분리, 박스 위치 부정확 |
| 운전자를 person 으로 검출 | 86개 사전 조사에서 6개 영상 관찰 | 운전자–자기 지게차 근접이 후보로 기록될 수 있음 |
| 앉은 작업자 누락 | 7_te2 person 검출 프레임 18.5% (육안으로는 계속 보임) | 근접 판정에서 작업자 누락 |
| 픽셀 거리 | 원근 미보정 | 화면 위·아래에서 같은 픽셀 거리가 다른 실제 거리 |

## 4. 공개 캡처 비식별 점검

- 대상: `outputs/day2/captures_public/v1/` 10장 (탐지 5 + ID 추적 5), `scripts/make_captures.py` 생성
- 처리: 사람 머리 영역(추적 결과 ∪ conf 0.05 재검출 ∪ 차량 영역 2배 확대 재검출) · 작업대 고정 마스크 · 큰 차량 운전석 추정 영역 모자이크, 픽셀 단위 적용 검증
- 육안 점검 결과(2026-11-17): 근·중거리 인물의 얼굴은 모두 모자이크되어 식별 불가. 모자이크되지 않은 인물은 화면 상단 원거리(머리 약 5~10px)뿐이며 식별 불가 수준으로 판단.
- **한계**: 자동 검증은 "검출된 영역에 모자이크가 적용되었는지"만 확인합니다. 사람 검출이 누락되면 처리되지 않으므로 **모든 사람의 비식별을 보장하지 않습니다.** 공개 전 사람이 최종 확인해야 하며, 블러 전 원본(`outputs/day2/captures/raw/`)은 공개하지 않습니다.
